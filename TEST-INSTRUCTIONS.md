# Инструкция по тестированию селективного сканирования

## Что было изменено

Добавлено модальное окно подтверждения сканирования:
- При нажатии "Сканировать выбранные папки" появляется окно с настройками
- В окне отображается список выбранных папок
- Чекбокс "Рекурсивное сканирование":
  - **Включено** → сканируется вся папка рекурсивно (все подпапки и файлы)
  - **Выключено** → сканируется только верхний уровень выбранной папки (без подпапок)
- Настройки количества потоков и CRC32 также в модальном окне

## Шаги для тестирования

### 1. Перезапустите сервер
```bash
npm start
```

### 2. Тест 1: Неrekursive сканирование (только верхний уровень)

1. Откройте веб-интерфейс: http://localhost:3000
2. Перейдите на вкладку "Сканирование"
3. Выберите диск P:
4. Разверните дерево до папки "Test Data"
5. Поставьте галочку на "Test Data"
6. Нажмите "Сканировать выбранные папки"
7. **В появившемся окне:**
   - Проверьте список выбранных папок
   - **СНИМИТЕ галочку "Рекурсивное сканирование"**
   - Настройте количество потоков (по желанию)
   - Нажмите "Начать сканирование"

**Ожидаемый результат в консоли сервера:**
```
📁 Added directory itself for non-recursive scan: P:\Test Data
📊 Non-recursive scan of P:\Test Data: found X items (including directory itself)
✅ Inserted/updated X records in database
```

**Ожидаемый результат в UI:**
```
Сканирование завершено (только верхний уровень): 1 папок обработано за X сек. Потоков: 8
```

### 3. Проверка базы данных

После сканирования запустите:
```bash
node check-db.js
```

**Ожидаемый результат:**
- Должна быть запись для папки `P:\Test Data` с `Is Directory: YES`
- Должны быть записи для файлов из верхнего уровня (если есть)
- НЕ должно быть записей для файлов из подпапок

### 4. Проверка в UI

1. Перейдите на вкладку "Поиск файлов"
2. Введите "Test Data" в поле поиска
3. Нажмите Enter или кнопку "Поиск"

**Ожидаемый результат:**
- Папка `P:\Test Data` должна отображаться в результатах поиска
- Должна быть помечена как директория (иконка папки)

### 5. Тест 2: Рекурсивное сканирование

1. Очистите базу данных (вкладка "Настройки" → "Очистить базу данных")
2. Перейдите на вкладку "Сканирование"
3. Разверните дерево до `P:\Test Data`
4. Поставьте галочку на "Test Data"
5. Нажмите "Сканировать выбранные папки"
6. **В появившемся окне:**
   - Проверьте список выбранных папок
   - **УБЕДИТЕСЬ что галочка "Рекурсивное сканирование" ВКЛЮЧЕНА** (по умолчанию)
   - Нажмите "Начать сканирование"

**Ожидаемый результат:**
- Все папки и файлы должны быть просканированы рекурсивно
- В базе должны быть все файлы из всех подпапок
- Сообщение: `Сканирование завершено (рекурсивно): 1 папок обработано...`

### 6. Тест 3: Сканирование нескольких папок

1. Очистите базу данных
2. Разверните дерево до `P:\Test Data`
3. Поставьте галочки на несколько подпапок (например, Photo и Documents)
4. Нажмите "Сканировать выбранные папки"
5. **В модальном окне:**
   - Проверьте что все выбранные папки отображаются в списке
   - Выберите режим сканирования (рекурсивно или нет)
   - Настройте параметры
   - Нажмите "Начать сканирование"

**Ожидаемый результат:**
- Все выбранные папки сканируются в выбранном режиме
- Сообщение показывает количество папок и режим сканирования
- В модальном окне видны все выбранные папки перед началом

## Устранение неполадок

### Папка не отображается в поиске

1. Проверьте консоль сервера на наличие ошибок
2. Запустите `node check-db.js` для проверки базы данных
3. Убедитесь, что кэш обновился (в консоли должно быть сообщение о инвалидации кэша)
4. Попробуйте обновить страницу в браузере (F5)

### Сканируется рекурсивно вместо селективного

1. Убедитесь, что чекбокс "Рекурсивное сканирование" СНЯТ
2. Проверьте в консоли сервера сообщение:
   - `📁 Added directory itself for non-recursive scan` = правильно
   - Если нет этого сообщения = проблема в передаче параметра recursive

### Ошибка при сканировании

1. Проверьте права доступа к папке
2. Убедитесь, что путь существует
3. Проверьте консоль сервера на наличие ошибок

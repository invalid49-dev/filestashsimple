# FileStash Simple

Простой и быстрый файловый менеджер на Node.js + SQLite.

## 🚀 Особенности

- **Простая архитектура**: Node.js + Express + SQLite + Vanilla JS
- **Быстрая работа**: Нет сложных зависимостей и фреймворков
- **Рекурсивное сканирование**: Сканирование папок с подпапками
- **Дерево папок**: Интуитивное разворачивание/сворачивание папок
- **Поиск файлов**: По имени, пути, расширению, CRC32
- **Статистика**: Количество файлов, папок, общий размер
- **Responsive дизайн**: Работает на всех устройствах

## 📦 Установка

### 🖱️ Простой способ (Windows)
1. **Запустите главное меню**: Двойной клик на `filestash.bat`
2. **Выберите "Setup"** для первоначальной настройки
3. **Выберите "Start Server"** для запуска приложения
4. **Выберите "Open Browser"** для открытия веб-интерфейса

### ⌨️ Командная строка
1. **Установите зависимости**:
   ```bash
   npm install
   ```

2. **Запустите сервер**:
   ```bash
   npm start
   ```

3. **Откройте в браузере**:
   ```
   http://localhost:3000
   ```

### 📁 Bat файлы для Windows
- `filestash.bat` - Главное меню с выбором действий

- `start-server.bat` - Запуск сервера
- `open-browser.bat` - Открытие веб-интерфейса

## ⚙️ Конфигурация

FileStash поддерживает гибкую настройку через переменные окружения. Создайте файл `.env` в корне проекта:

```bash
# Стратегия кэширования (optimized рекомендуется для больших баз данных)
CACHE_STRATEGY=optimized

# Размер горячего кэша (количество записей в памяти)
HOT_CACHE_SIZE=10000

# Максимальное количество результатов поиска
SEARCH_LIMIT=1000

# Порт сервера
PORT=3000

# Включить статистику кэша
ENABLE_CACHE_STATS=true
```

### 📦 Настройка архиваторов

FileStash поддерживает создание архивов в форматах ZIP, RAR и 7Z. Приложение автоматически определяет доступные архиваторы при запуске.

#### Использование локальных архиваторов (рекомендуется)

Для работы без системной установки архиваторов:

1. **Создайте директории**:
   ```
   bin/7zip/
   bin/winrar/
   ```

2. **Скачайте портативные версии**:
   - **7-Zip**: [7-Zip Extra (standalone console version)](https://www.7-zip.org/download.html)
   - **WinRAR**: [WinRAR command line version](https://www.rarlab.com/download.htm)

3. **Распакуйте файлы**:
   - Поместите `7z.exe` в `bin/7zip/`
   - Поместите `Rar.exe` в `bin/winrar/`

4. **Перезапустите приложение**

#### Использование системных архиваторов

Если архиваторы установлены системно, приложение автоматически их обнаружит:
- **7-Zip**: `C:\Program Files\7-Zip\7z.exe` или в PATH
- **WinRAR**: `C:\Program Files\WinRAR\Rar.exe` или в PATH

#### Поддерживаемые форматы

- **ZIP**: Создается с помощью 7-Zip (универсальный формат)
- **7Z**: Создается с помощью 7-Zip (высокая степень сжатия, формат по умолчанию)
- **RAR**: Создается с помощью WinRAR (требует WinRAR)

#### Приоритет обнаружения

1. Локальные архиваторы в `bin/` директории
2. Системные архиваторы в стандартных путях
3. Архиваторы в PATH

При запуске приложение выводит в консоль информацию о найденных архиваторах:
```
📦 Archiver Detection:
   7-Zip: ✅ Local (bin/7zip/7z.exe)
   WinRAR: ✅ Local (bin/winrar/Rar.exe)
   Supported formats: zip, rar, 7z
```

#### Устранение неполадок

**Архиваторы не обнаружены**:
- Проверьте наличие файлов `7z.exe` и `Rar.exe` в соответствующих директориях
- Убедитесь, что файлы не заблокированы Windows (Свойства → Разблокировать)
- Проверьте права доступа к файлам

**Ошибка при создании архива**:
- Убедитесь, что выбранный формат поддерживается доступным архиватором
- Проверьте наличие свободного места на диске
- Проверьте права доступа к целевой директории

### Стратегии кэширования

- **optimized** (рекомендуется): Трехуровневое кэширование, ~190-230MB для 1.3M файлов
- **full**: Полная загрузка БД в память, ~1000MB для 1.3M файлов

## 🔧 API Endpoints

### Файловая система
- `GET /api/drives` - Получить доступные диски
- `GET /api/browse?path=<path>` - Обзор папок в указанном пути
- `POST /api/scan-multiple` - Сканировать выбранные папки (с поддержкой селективного сканирования)
- `GET /api/scan/progress/:scanId` - Получить прогресс сканирования
- `POST /api/scan/stop/:scanId` - Остановить сканирование

### Файлы
- `GET /api/files` - Получить список файлов (с поиском и пагинацией)
- `GET /api/files/tree` - Получить дерево файлов
- `GET /api/files/:id` - Получить файл по ID
- `DELETE /api/files/:id` - Удалить запись файла
- `POST /api/files/rescan` - Пересканировать файлы

### Архивы
- `GET /api/archivers` - Получить список доступных архиваторов и форматов
- `POST /api/files/archive` - Создать архив из выбранных файлов
- `GET /api/archive/progress/:archiveId` - Получить прогресс создания архива (SSE)

### Статистика и управление
- `GET /api/stats` - Получить статистику
- `POST /api/clear` - Очистить базу данных
- `GET /api/cache/stats` - Получить статистику кэша (если включено)

## 💡 Использование

### 1. Сканирование папок
1. Выберите диск из списка
2. Введите путь к папке или нажмите "Обзор папок"
3. Разверните нужные папки в дереве
4. Выберите папки для сканирования (чекбоксы)
5. Нажмите "Сканировать выбранные папки"
6. **В появившемся окне подтверждения:**
   - Проверьте список выбранных папок
   - Выберите режим сканирования:
     - ☑️ **Рекурсивное сканирование** - сканирует все подпапки
     - ☐ **Рекурсивное сканирование** - сканирует только верхний уровень
   - Настройте количество потоков (рекомендуется 8-16)
   - Выберите вычисление CRC32 (для поиска дубликатов)
7. Нажмите "Начать сканирование"

**Совет**: Используйте неrekursive сканирование для быстрого добавления папок в базу без сканирования всего содержимого.

### 2. Поиск файлов
1. Перейдите на вкладку "Поиск файлов"
2. Введите поисковый запрос
3. Нажмите "Поиск" или Enter

### 3. Создание архивов
1. Выберите файлы в списке (чекбоксы)
2. Нажмите "Создать архив"
3. Выберите формат архива (ZIP, RAR или 7Z)
4. Введите имя архива
5. Выберите папку назначения
6. Нажмите "Создать"
7. Следите за прогрессом в модальном окне

**Примечание**: Доступные форматы зависят от установленных архиваторов.

### 4. Управление данными
1. Перейдите на вкладку "Настройки"
2. Используйте "Очистить базу данных" для удаления всех записей

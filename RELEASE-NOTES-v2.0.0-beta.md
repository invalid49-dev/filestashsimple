# Filestash Beta v2.0.0 🚀

## 🎉 Основные изменения

### ✨ Новые функции

#### 1. Модальное окно подтверждения сканирования
- При нажатии "Сканировать выбранные папки" теперь появляется окно с настройками
- Отображается список всех выбранных папок перед началом сканирования
- Все настройки сканирования собраны в одном месте

#### 2. Селективное сканирование
- **Рекурсивное сканирование** (включено по умолчанию) - сканирует папку и все подпапки
- **Неrekursive сканирование** - сканирует только верхний уровень выбранной папки
- Гибкий выбор режима для каждого сканирования

#### 3. Поддержка локальных архиваторов
- Автоматическое определение архиваторов в папке `bin/`
- Поддержка портативных версий 7-Zip и WinRAR
- Приоритет локальных архиваторов над системными
- Выбор формата архива: ZIP, RAR, 7Z

#### 4. Улучшенный UI архивации
- Модальное окно с выбором формата архива
- Отображение доступных форматов в зависимости от установленных архиваторов
- Прогресс создания архива в реальном времени

### 🐛 Исправления ошибок

#### Исправлен неверный подсчет файлов при рекурсивном сканировании
- **Проблема**: При сканировании показывалось ~1238 элементов вместо 439
- **Причина**: Директории считались дважды
- **Решение**: Изменена логика подсчета в `getAllItemsRecursivelyOptimized()`
- Теперь каждая директория и файл считаются только один раз

### 🔧 Улучшения производительности

- Оптимизирована функция рекурсивного сканирования
- Улучшено логирование процесса сканирования
- Добавлены метки прогресса для отладки

## 🔄 Миграция

### Для пользователей v1.x

1. **Обновите зависимости**:
   ```bash
   npm install
   ```

2. **Настройте локальные архиваторы** (опционально):
   - Создайте папки `bin/7zip/` и `bin/winrar/`
   - Скачайте портативные версии архиваторов
   - Поместите `7z.exe` в `bin/7zip/`
   - Поместите `Rar.exe` в `bin/winrar/`

3. **Перезапустите сервер**:
   ```bash
   npm start
   ```

### Изменения в API

Новые endpoints:
- `GET /api/archivers` - Получить список доступных архиваторов

Изменения в существующих endpoints:
- `POST /api/files/archive` - Добавлен параметр `format` для выбора формата архива
- `POST /api/scan-multiple` - Улучшена поддержка параметра `recursive`

## 🧪 Тестирование

Для тестирования новых функций:

1. **Тест селективного сканирования**:
   - Выберите папку без дочерних
   - Отключите "Рекурсивное сканирование"
   - Проверьте, что сканируется только верхний уровень

2. **Тест модального окна**:
   - Выберите несколько папок
   - Нажмите "Сканировать"
   - Проверьте отображение списка папок

3. **Тест архивации**:
   - Выберите файлы
   - Создайте архив в разных форматах
   - Проверьте доступность форматов

Подробные инструкции: `TEST-INSTRUCTIONS.md`

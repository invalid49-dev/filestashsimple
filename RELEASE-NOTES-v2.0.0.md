# Release Notes v2.0.0

## 🎉 FileStash Simple v2.0.0 - Performance Revolution

Этот релиз полностью переработал производительность приложения, сделав его пригодным для работы с базами данных любого размера.

### 🚀 Ключевые улучшения

#### 1. Мгновенная загрузка базы данных
- База данных теперь загружается в память при старте
- Вкладка "База данных" открывается за 100-500ms вместо 15-30 секунд
- Работает с базами до 500k+ записей

#### 2. Ленивая загрузка дерева файлов
- Дерево загружается по уровням (только при раскрытии)
- Никаких зависаний браузера
- Использует в 4-10 раз меньше памяти

#### 3. Умный поиск
- Результаты ранжируются по релевантности
- Поиск по нескольким словам
- Результаты можно раскрывать как дерево

#### 4. Полная поддержка операций
- "Выбрать все" работает в дереве
- Копирование, перемещение, архивирование, удаление
- Работает с файлами из поиска

### 📊 Производительность

| Размер базы | Загрузка (было) | Загрузка (стало) | Улучшение |
|-------------|-----------------|------------------|-----------|
| 20k файлов  | ~15 секунд      | ~200ms           | 75x       |
| 100k файлов | ~2 минуты       | ~500ms           | 240x      |
| 392k файлов | ~10+ минут      | ~5 секунд        | 120x+     |

### 🔧 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/filestash-simple.git
cd filestash-simple

# Установить зависимости
npm install

# Запустить
npm start
# или
start-server.bat
```

### 📝 Обновление с v1.x

1. Сделайте бэкап базы данных (на всякий случай)
2. Обновите код: `git pull origin main`
3. Установите зависимости: `npm install`
4. Перезапустите сервер
5. Очистите кэш браузера (Ctrl+F5)

База данных полностью совместима, миграция не требуется!

### 🐛 Известные ограничения

- Первое раскрытие папки требует загрузки с сервера (~50-200ms)
- Поиск ограничен 1000 результатами для производительности
- Очень большие папки (1000+ файлов) могут загружаться дольше

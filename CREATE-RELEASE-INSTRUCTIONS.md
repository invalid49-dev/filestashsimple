# Инструкция по созданию релиза Filestash Beta v2

## ✅ Что уже сделано

1. ✅ Создан Git тег `v2.0.0-beta`
2. ✅ Тег отправлен на GitHub
3. ✅ Подготовлены release notes в файле `RELEASE-NOTES-v2.0.0-beta.md`

## 📝 Создание релиза на GitHub (вручную)

### Шаг 1: Откройте страницу релизов

Перейдите по ссылке:
```
https://github.com/invalid49-dev/filestashsimple/releases/new
```

Или:
1. Откройте репозиторий: https://github.com/invalid49-dev/filestashsimple
2. Нажмите на вкладку "Releases" (справа)
3. Нажмите кнопку "Draft a new release"

### Шаг 2: Выберите тег

- В поле "Choose a tag" выберите `v2.0.0-beta` из списка
- Тег уже создан и отправлен на GitHub

### Шаг 3: Заполните информацию о релизе

**Release title (Название релиза):**
```
Filestash Beta v2
```

**Description (Описание):**

Скопируйте содержимое файла `RELEASE-NOTES-v2.0.0-beta.md` или используйте краткую версию:

```markdown
# Filestash Beta v2.0.0 🚀

## 🎉 Основные изменения

### ✨ Новые функции

- **Модальное окно подтверждения сканирования** - все настройки в одном месте
- **Селективное сканирование** - выбор между рекурсивным и неrekursive режимом
- **Поддержка локальных архиваторов** - портативные версии 7-Zip и WinRAR
- **Выбор формата архива** - ZIP, RAR, 7Z

### 🐛 Исправления

- Исправлен неверный подсчет файлов при рекурсивном сканировании
- Улучшена логика обработки директорий

### 📚 Документация

- Добавлены подробные руководства по новым функциям
- Обновлен README с инструкциями

## 📋 Полный список изменений

- 154 файла изменено
- 5,516 строк добавлено
- 751 строка удалена
- 8 новых функций
- 3 исправления ошибок

## 🔗 Документация

- [Руководство по сканированию](SCAN-MODAL-GUIDE.md)
- [Инструкции по тестированию](TEST-INSTRUCTIONS.md)
- [Полные release notes](RELEASE-NOTES-v2.0.0-beta.md)

---

**Статус**: Beta (тестирование)
```

### Шаг 4: Настройте параметры релиза

- ☑️ **Отметьте "Set as a pre-release"** (это beta версия)
- ☐ Не отмечайте "Set as the latest release" (это beta)

### Шаг 5: Опубликуйте релиз

Нажмите кнопку **"Publish release"**

## 🚀 Альтернативный способ (через GitHub CLI)

Если у вас установлен GitHub CLI (`gh`):

```bash
gh release create v2.0.0-beta \
  --title "Filestash Beta v2" \
  --notes-file RELEASE-NOTES-v2.0.0-beta.md \
  --prerelease
```

## 📦 Добавление файлов к релизу (опционально)

Если хотите добавить архив с исходным кодом или другие файлы:

1. После создания релиза откройте его страницу
2. Нажмите "Edit release"
3. Перетащите файлы в секцию "Attach binaries"
4. Нажмите "Update release"

# Исправление: Неверный подсчет файлов при рекурсивном сканировании

## Проблема

При рекурсивном сканировании папки `Test Data` (439 файлов) система показывала ~1238 элементов.

## Причина

В функции `getAllItemsRecursivelyOptimized()` директории добавлялись в список items дважды:
1. Один раз как сама директория при обработке
2. Второй раз как элемент при чтении содержимого родительской директории

```javascript
// БЫЛО (неправильно):
const currentDir = directories.pop();
items.push(currentDir);  // Добавляем директорию

// ... затем при чтении содержимого:
for (const result of itemResults) {
    if (result) {
        items.push(result.fullPath);  // Добавляем ВСЕ элементы (включая директории)
        if (result.isDirectory) {
            directories.push(result.fullPath);
        }
    }
}
```

Это приводило к дублированию директорий в подсчете.

## Решение

Изменена логика добавления элементов:
- Директории добавляются в items только при их обработке из очереди
- При чтении содержимого директории:
  - Поддиректории добавляются ТОЛЬКО в очередь для обработки
  - Файлы добавляются в items

```javascript
// СТАЛО (правильно):
const currentDir = directories.pop();
items.push(currentDir);  // Добавляем директорию

// ... затем при чтении содержимого:
for (const result of itemResults) {
    if (result) {
        if (result.isDirectory) {
            // Поддиректория - только в очередь
            directories.push(result.fullPath);
        } else {
            // Файл - в items
            items.push(result.fullPath);
        }
    }
}
```

## Результат

Теперь подсчет правильный:
- **Test Data**: 439 файлов → показывает ~439 элементов (файлы + директории)
- Каждая директория считается один раз
- Каждый файл считается один раз


4. Проверьте количество в модальном окне прогресса
5. Должно показывать правильное количество элементов

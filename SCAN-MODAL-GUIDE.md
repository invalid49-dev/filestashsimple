# Руководство по модальному окну сканирования

## 🎯 Что изменилось

Теперь при нажатии кнопки "Сканировать выбранные папки" появляется модальное окно с подтверждением и настройками сканирования.

## 📋 Содержимое модального окна

### 1. Список выбранных папок
Отображает все папки, которые вы выбрали для сканирования.

### 2. Рекурсивное сканирование (чекбокс)
- **☑️ Включено (по умолчанию)**: Сканирует папку и все её подпапки рекурсивно
- **☐ Выключено**: Сканирует только верхний уровень папки (без подпапок)

### 3. Количество потоков
- Настройка производительности сканирования
- По умолчанию: 8 потоков
- Рекомендуется: 8-16 потоков для современных процессоров

### 4. Вычислять CRC32
- **☑️ Включено (по умолчанию)**: Вычисляет контрольные суммы для поиска дубликатов
- **☐ Выключено**: Быстрее, но без возможности поиска дубликатов

## 🚀 Как использовать

### Пример 1: Быстрое сканирование только верхнего уровня

```
1. Выберите папку P:\Test Data
2. Нажмите "Сканировать выбранные папки"
3. В модальном окне:
   - Снимите галочку "Рекурсивное сканирование"
   - Снимите галочку "Вычислять CRC32" (для скорости)
   - Нажмите "Начать сканирование"

Результат: Быстрое сканирование только файлов в P:\Test Data
```

### Пример 2: Полное рекурсивное сканирование с CRC32

```
1. Выберите папку P:\Test Data
2. Нажмите "Сканировать выбранные папки"
3. В модальном окне:
   - Оставьте галочку "Рекурсивное сканирование" (включена по умолчанию)
   - Оставьте галочку "Вычислять CRC32" (включена по умолчанию)
   - Установите потоки: 16 (для быстрого сканирования)
   - Нажмите "Начать сканирование"

Результат: Полное сканирование всех файлов с вычислением CRC32
```

### Пример 3: Сканирование нескольких папок

```
1. Выберите несколько папок:
   - P:\Test Data\Photos
   - P:\Test Data\Documents
   - P:\Test Data\Videos
2. Нажмите "Сканировать выбранные папки"
3. В модальном окне:
   - Проверьте что все 3 папки в списке
   - Выберите режим сканирования
   - Нажмите "Начать сканирование"

Результат: Все выбранные папки сканируются в одном режиме
```

## 💡 Преимущества нового подхода

1. **Наглядность**: Видите все выбранные папки перед началом
2. **Гибкость**: Настраиваете параметры для каждого сканирования
3. **Контроль**: Можете отменить операцию до начала
4. **Удобство**: Все настройки в одном месте

## ⚙️ Настройки по умолчанию

- Рекурсивное сканирование: **Включено**
- Количество потоков: **8**
- Вычислять CRC32: **Включено**

Эти настройки оптимальны для большинства случаев использования.

## 🔧 Рекомендации по производительности

### Для быстрого сканирования:
- Отключите CRC32
- Увеличьте количество потоков (16-24)
- Используйте неrekursive режим если нужны только папки

### Для полного анализа:
- Включите CRC32
- Используйте рекурсивный режим
- Установите 8-12 потоков (баланс скорости и нагрузки)

### Для больших дисков:
- Сканируйте по частям (выбирайте отдельные папки)
- Используйте 16+ потоков
- Включите CRC32 только если нужен поиск дубликатов
